# MetaSweeper Third-Party Plugins

This public repository contains the `training_stats` plugin for MetaSweeper. The plugin package is in `training_stats/`; the repository root contains development documentation and tests.

- Plugin overview and installation: [training_stats/README.md](training_stats/README.md)
- GitHub Topic and release tag instructions: [PUBLISHING.md](PUBLISHING.md)
- Development environment: this repository's `.venv`, independent of the MetaSweeper host repository

To make the plugin discoverable in MetaSweeper's marketplace, add the GitHub repository Topic `metasweeper-plugin`. Publish a release by pushing a tag such as `metasweeper-v1.0.0`.
